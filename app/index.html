    How DeckChek works

    Devices holds your own gear with a researched test plan per device; results are saved per unit. Or pick a workflow on the left. Each one walks you through Setup (what you need, wiring, source), Capture (live meters with clip latch) and Results (verdict first, then readings with ± uncertainty, findings and raw evidence). In the browser preview, load a recorded file instead of capturing live.

    Keyboard shortcuts

    SpaceStart / stop capture (Capture step)
    EscCancel capture, close panel or dialog; on Devices, go back one level
    Ctrl + 1…9, 0Switch screen in rail order: 1–5 workflows, 6 Calibration, 7 System Health, 8 Devices, 9 Equipment, 0 History
    Ctrl + EExport the current report (System Health: the system report; Devices: the device report for the selected unit)
    Ctrl + SSave run (runs autosave) and mark it as the baseline
    IToggle the details panel
    Ctrl + Shift + CClear clip indicators
    Ctrl + Shift + TToggle light / dark theme
