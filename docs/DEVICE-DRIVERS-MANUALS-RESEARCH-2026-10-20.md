## Import data contract

For every profile preserve manufacturer, model, exact variant, category, official product page, manual URL, download/driver page, firmware/download timestamp, OS-specific requirements, DJ-software integrations, feature list, per-control test applicability, provenance, verification date and capabilities requiring physical validation. Do not invent direct download URLs, VID/PID, MIDI message codes or service manuals. Public service-manual availability is a separate field and defaults to `unknown`.

Use `MANUFACTURER_PUBLISHED` or `OFFICIAL_MANUAL` for sourced assertions, `NOT_TESTED` for physical tests not run, and separate `guide/manual` vs `automatic/MIDI` runners. Prior to enabling in DeckChek, deduplicate against `app/devices/profiles`, conform to the existing profile schema, regenerate `tools/build-device-index.mjs`, validate and execute test suites. The research registry is not itself imported into the runtime database.
