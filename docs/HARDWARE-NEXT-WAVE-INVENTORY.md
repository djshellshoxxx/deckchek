## Acceptance gates per model
- Document precise model / revision / release or generation; never mix MK generations.
- Inventory every exposed testable control and I/O grouped by actual transport.
- Record source URL and level of certainty per claim.
- List verified manufacturer software/driver dependencies and actual driver links.
- Include user manual, MIDI list, service manual if public, firmware and support/forum; blank if not found.
- For audio paths: routing diagram, physical connector and calibration prerequisites.
- For mechanical paths: observation versus true measured specification.
- For MIDI: message map only when published or captured from real hardware.
- Add deterministic schema/index tests and staged device checks.
- Do not declare support until full profile validity, test prerequisites and manufacturer source coverage.
