# DeckChek Wiki

DeckChek (Circuit Drift Labs) is a DJ hardware diagnostic workstation. It measures, compares, diagnoses, trends and documents
DJ playback hardware and signal paths: turntables and cartridges, CDJs and media players, controllers, and DVS setups. It is not
a music player. The current build is a live-capture and offline-analysis beta, with a Windows desktop shell.
