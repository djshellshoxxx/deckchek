### Ownership boundaries after the MIDI corrections

The browser and native fixes distinguish captured connections from new selection. Failed name reads remain unselectable, and observed duplicate names cannot create a new arbitrary connection. Existing captured output cleanup remains with its original binding, including when a duplicate name later appears. Known output failure or disappearance now requires explicit reset before selecting a replacement. Closing an input does not reset its output; this preserves owned Note Off cleanup.

The native request mutex is held only for short generation bookkeeping. Close releases it before waiting on the connection mutex, and workers check their token under the connection mutex before driver access. Independent contention probes found no reverse-order nested lock. The controlled harness requires `Send` bounds but substitutes scheduling, MIDI I/O and serialization; it is not a real Tauri build or driver test. No stable physical identity through an unobserved operating-system substitution, renderer-delivery acknowledgement, hardware timing accuracy or audible cleanup is established by these tests.

### Restore review boundaries and compatibility
